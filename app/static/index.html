No hops — one passage
A specific definition, a policy line, an exact string. You already know what you are looking for and want the place it is written.
1 hop — the immediate trail
Everywhere else the names in your question appear: the other uses of a function, the price list for a part number, the documents naming a project. Finds pages that share no wording with your question at all.
2 hops — the wider map
Follows those names' names in turn, for tracing how things connect across several files. Casts a much wider net, so expect more noise.

Semantic search — best for “where is X done?”. With keyword on, exact strings are found too, so grep is only needed for files outside the index. Hops pulls in files connected by a shared name — the other places a function, part number or project is mentioned. Same index the API serves on POST /search and /search/full.

Answers are written from the passages this index retrieves, and cite them — click a 1 to see which document it came from. The filters above apply to what gets retrieved for each question. Nothing is stored: reloading the page starts a new conversation.
